## Overview

This project was developed for the Applied AI in Business course at the Swiss School of Business and Management (SSBM). It uses transactional retail data to identify meaningful customer groups and translate the resulting insights into marketing recommendations and decision support.

The analysis combines RFM (Recency, Frequency, Monetary) customer segmentation with unsupervised machine learning using K-Means clustering. RFM provides interpretable customer segments for marketing actions, while K-Means offers a complementary data-driven perspective on customer behaviour.

An interactive dashboard was also developed in Google Data Studio to present the main customer, segment, value, and geographic insights.

## Analytical Approach

The project follows the analytical workflow below:

1. Data loading and initial inspection
2. Data quality assessment
3. Data cleaning and preprocessing
4. Exploratory data analysis
5. RFM feature engineering
6. Rule-based RFM customer segmentation
7. Unsupervised machine learning validation using K-Means
8. Customer and segment profiling
9. Dashboard dataset preparation and validation
10. Marketing recommendations
11. Implementation planning and performance measurement

The final RFM segmentation contains six business-oriented customer groups:

- Champions
- Loyal Customers
- Potential Loyalists
- Needs Attention
- At Risk
- Hibernating

K-Means clustering is used as a complementary analytical layer rather than as a replacement for the RFM segmentation. The dashboard remains centred on RFM because these segments provide more interpretable categories for marketing decision-making.

## Reproducibility and Validation

The final notebook was tested using a complete kernel restart followed by execution of all cells in sequence.

The analytical workflow includes several validation steps:

- RFM metrics are calculated from the cleaned transactional data.
- Customer segments are generated using defined RFM rules.
- K-Means input features are standardized before clustering.
- Alternative numbers of clusters are evaluated using inertia and silhouette scores.
- Cluster profiles are compared with the business-defined RFM segments.
- Extreme high-value observations are retained only after transaction-level validation.
- Dashboard metrics are cross-validated against independently calculated Python results.
- The dashboard export contains 4,338 customer records and 11 fields.

## Data Source

The analysis uses the **Online Retail** dataset from the UCI Machine Learning Repository.

The dataset contains transactional records from a UK-based non-store online retailer, including invoice, product, quantity, transaction date, unit price, customer, and country information.
